# 付箋のタイトル・内容を隠す

## 自分の付箋

上部の「編集」の隣にある**目のアイコン**を押すと、タイトル・本文・写真・表・チェックリスト・期限を隠します。「内容を非表示中」と操作ボタンだけが残ります。もう一度押すと表示します。マウスを重ねると操作名を確認できます。

非表示の設定は付箋と一緒に暗号化して保存し、画面更新・再ログイン後も維持します。内容を削除する機能ではありません。保存に失敗した場合はエラーを表示し、最後に保存できた設定のままになります。位置・サイズ・色は変えません。

付箋カードにはタイトルを表示せず、本文を上に詰めて表示します。付箋の作成・編集・送信・受信閲覧画面にもタイトル欄は出しません。本文や表・写真だけで保存でき、新規作成時は本文にカーソルが入ります。既存のタイトルデータは互換性のため保持します。タスク・投稿のタイトル欄は引き続き使用できます。「−」による最小化は別の設定で、非表示を解除しても最小化の状態は維持します。

上部のアイコンと「⋮⋮」は付箋にマウスを重ねたときだけ表示します。キーボード操作ではフォーカスが当たったボタンを表示します。受信付箋の上部アイコンも同様です。

非表示・最小化中も、上部左端の「⋮⋮」または操作行のボタン以外の部分をドラッグして移動できます。「内容を非表示中」の文字からも移動できます。本文は文字の選択やチェック操作に使うため、移動の開始位置にはしません。「◆」で位置を固定している場合は、もう一度「◆」を押して固定を解除してください。

## ほかのユーザーから届いた付箋

受信BOXでは、既存の受信付箋も新しく届く付箋も、最初はタイトル・内容を隠します。送信者名と未読・既読の状態は表示します。

- 上部の目のアイコンを押すと、その受信付箋の内容を表示します。もう一度押すと隠します。
- 「開く」を押すと、読み取り専用画面で内容を表示します。閉じても一覧の非表示設定は解除しません。
- 表示または開封したときに既読にします。一覧を見るだけでは既読になりません。再び隠しても未読には戻しません。
- 「未読のみ」の表示中でも、目のアイコンで表示した付箋は、読み終わって隠すまで一覧に残します。表示直後に既読となって消えることを防ぎます。
- 受信付箋の表示切替は、ログイン中の自分の画面だけに反映します。画面の通常更新では維持し、ページの再読み込み・再ログインでは非表示へ戻します。送信者やほかの受信者の表示には影響しません。
- 自分の付箋へコピーした場合も、保存後の付箋は非表示から始まります。

## 表示範囲と注意

非表示の付箋は、全体検索やゴミ箱でもタイトル・本文を伏せます。非表示のままタスク化した場合も、タスク一覧のタイトル・期限を伏せます。タスク一覧の目のアイコンでも表示を切り替えられます。検索対象から除外するわけではないので、検索語に一致した非表示の付箋は「内容を非表示中」と表示します。

「編集」「開く」「送る」「投稿する」など、内容を確認する操作を選んだ場合は、確認・編集画面で実際の内容を表示します。送信・投稿される内容を空にする機能ではなく、投稿先で非表示になる機能でもありません。

これは画面上ののぞき見を減らす表示機能です。追加のパスワードやアクセス権によるロックではありません。離席時は画面上部の「ロック」を使用してください。

新しいSharePointリスト・列の追加は不要です。
