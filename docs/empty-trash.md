# ゴミ箱を空にする

1. 上部メニューの「ゴミ箱」を開きます。
2. 「ゴミ箱を空にする」を押します。空の場合は押せません。
3. 対象件数を確認し、削除に同意します。キャンセルすると変更しません。

自分のゴミ箱にある個人付箋・タスクだけが対象です。通常の付箋、アーカイブ、受信付箋、送信履歴、投稿、ほかのユーザーのデータは対象にしません。確認した項目だけを処理し、後からゴミ箱へ追加された項目は含めません。

空にした項目は**このアプリから復元できません**。タイトル・本文・写真への参照・変更履歴を削除済み情報に置き換えます。削除前の確認画面には、非表示のタイトルや本文を出しません。

途中で失敗した場合は処理を止め、削除を確認できた件数とエラーを表示して一覧を再取得します。削除済みの項目を元に戻すことはできません。通信断ではサーバー側だけで処理済みの場合もあるため、再取得した一覧を確認してください。別の操作で復元された項目や競合が発生した項目は上書き削除しません。

## 保存先について

内部ではIDの再利用や参照切れを防ぐため、削除済みの最小限の暗号化情報と既存の宛先鍵の行を残します。SharePointの添付保管用行（BLOB）、過去のバージョン、バックアップは一括削除しません。これはアプリのゴミ箱を空にする機能であり、保存先全体の完全消去や容量回収を保証する機能ではありません。

SharePointリスト・列の追加は不要です。
