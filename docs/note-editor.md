# 付箋の表編集

本文欄を、HTMLタグではなく表や太字をそのまま表示・編集する入力欄に変更しました。

## 表を入れる

1. 「新しい付箋」を開き、本文の挿入したい場所をクリックします。
2. 「表」を押します。見出しと入力欄を含む3行・2列の表が入ります。
3. セルをクリックして文字を入力します。「項目」「内容」の見出しも変更できます。
4. 「保存する」を押します。保存した付箋や再編集画面にも表の形で表示します。

「行追加」は選択セルの下、「列追加」は右に追加します。Tabで次のセル、Shift+Tabで前のセルへ移動します。最後のセルでTabを押すと行を追加します（結合セルのある表や行数上限では通常のフォーカス移動）。「表削除」は確認後に選択中の表を本文から除きます。保存前の変更は「キャンセル」で破棄できます。

## 貼り付けと既存データ

- HTMLの表、またはタブ区切りの文字列をコピーして本文へ貼り付けると表として挿入します。IE11向けにはテキスト取得の代替処理を用意しています。
- 内容・行列・結合セルは保持しますが、外部の色・幅・フォントなどの装飾は引き継がず、アプリの表の書式を使います。スクリプト・外部画像URL・外部リンクなどは取り除きます。写真は [写真の貼り付け](photo-sharing.md) を使ってください。
- 結合セルの文字は編集できます。結合セルを含む表の行・列追加は、元の表で変更して貼り付け直してください。
- 表の中に別の表を挿入・貼り付けることはできません。
- 行追加とタブ区切り貼り付けは100行まで、列追加とタブ区切り貼り付けは20列までです。本文は写真データを除き、表のHTML・書式を含む20000文字までです。上限超過は表示し、保存を止めます。
- 既存の付箋に保存された表のHTMLも表として開けます。通常の改行・太字・チェックリスト・変更履歴・コピー・タスク化は継続して使用できます。
- 本文は既存の暗号化データ内の文字列として保存します。SharePointリスト・列の追加は不要です。大きなデータにはStickyNotesの添付ファイル機能を使用します。
- 受信付箋などの読み取り専用画面でも表を表示します。変更するには「コピー」で自分の付箋にしてください。

## 確認範囲

DOMを使う自動テストで、挿入・セル編集・行列追加・Tab移動・保存と再編集・履歴・貼り付け・チェックリスト・読み取り専用・入力上限・危険なHTMLの除去を確認しています。接続されたブラウザーがないため、IE11・Edge95実機での描画、実際のExcelクリップボード、IME操作は未確認です。

入力欄は [contenteditable](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/contenteditable)、挿入位置は [DOM Range](https://developer.mozilla.org/en-US/docs/Web/API/Range/insertNode)、貼り付けは [ClipboardEvent](https://developer.mozilla.org/en-US/docs/Web/API/ClipboardEvent/clipboardData) を使用し、配布コードはES5構文を維持しています。
